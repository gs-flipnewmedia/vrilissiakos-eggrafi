# Αίτηση Εγγραφής – Βριλησσιακός Α.Ο.

Ψηφιακή αίτηση εγγραφής για την Ακαδημία Μπάσκετ του Βριλησσιακού Αθλητικού Ομίλου.
Είναι Progressive Web App για tablet και λειτουργεί και χωρίς internet.

- Μορφή μίας σελίδας ή σε βήματα, με έλεγχο στοιχείων πριν την υπογραφή
- Υπογραφή γονέα/κηδεμόνα στην οθόνη
- Αποστολή στο Google Sheet της ομάδας: μία γραμμή και ένα PDF ανά αίτηση (βλ. [`google-apps-script/`](google-apps-script/README.md))
- Εναλλακτικά, εξαγωγή σε Excel (CSV), JSON ή εκτύπωση/PDF από τη συσκευή

Ο κώδικας **δεν** περιέχει προσωπικά δεδομένα ούτε κωδικούς. Οι αιτήσεις φυλάγονται μόνο στο tablet,
μέχρι να σταλούν στο Google Sheet της ομάδας.

## Τοπική εκτέλεση

```bash
python -m http.server 5173
```

Μετά ανοίξτε τη διεύθυνση http://localhost:5173

## Δημοσίευση

Η εφαρμογή φιλοξενείται στο GitHub Pages, από το branch `main` και τον φάκελο `/ (root)`.
Μετά από κάθε αλλαγή αρχείων, αυξήστε την έκδοση `CACHE` στο `sw.js`, ώστε τα tablet να πάρουν τη νέα έκδοση.

## Διαχείριση

Το κουμπί «Διαχείριση» βρίσκεται στο κάτω μέρος της σελίδας. Το αρχικό PIN είναι `1234` και αλλάζει από τις Ρυθμίσεις.
